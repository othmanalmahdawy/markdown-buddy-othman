
# Student Performance Analysis

## Project Overview

This project analyzes a synthetic student dataset using R programming. It explores the relationship between study hours and student assessment scores.

## Project Objectives

- Create a student dataset.
- Analyze student assessment scores.
- Calculate descriptive statistics.
- Visualize the relationship between study hours and scores.

## Installation

Install R and RStudio.

Install the required R package:

```r
install.packages("ggplot2")
```

## Example Usage

Open the R project and run:

```r
source("student_performance_analysis.R")
```

The script creates a synthetic dataset, calculates basic statistics, and generates a scatter plot.

## Inputs

The dataset contains three variables:

- `student_id`: Student identification number.
- `study_hours`: Number of study hours.
- `score`: Student assessment score.

## Outputs

- Student dataset.
- Mean, maximum, and minimum scores.
- Summary statistics.
- Scatter plot of study hours and student scores.
