## AI Assistance Reflection

### 1. How did AI assistance help you with this assignment?

ChatGPT helped me organize the README structure, understand Markdown formatting, and improve the documentation of my R project.

### 2. What did you learn about Markdown and R Markdown?

I learned how to use Markdown headings, lists, and code blocks. I also learned how to use R Markdown to combine explanations, executable R code, statistical results, and visualizations in one report.

### 3. Why is it important to verify AI-generated suggestions?

It is important to verify AI-generated suggestions because they may contain errors or inaccurate information. Running the code in RStudio and checking the results helps ensure that the final project is accurate and reliable.
